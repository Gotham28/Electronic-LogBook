# Task Log

Append-only record of completed tasks, oldest first. Newest entries go at the END.

RULES
- Never edit or delete an existing entry. Ever. If an entry was wrong, add a new dated
  entry correcting it.
- One entry per completed task, added only after the task's evidence has been reviewed
  and accepted.
- Antigravity drafts the entry; the developer approves it; only then is it written.
- Do not backfill entries for work done before this file existed. The log starts here.
